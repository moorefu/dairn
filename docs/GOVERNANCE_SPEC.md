# Dairn

AI-Native Software Engineering Toolkit.

Project policy: `.dairn/governance/project.json`; authoritative reference specs: `dairn docs find <topic>`.

Capability-driven analysis: `dairn analyze plan [--base <ref>] [--apply]` derives needs, reuses valid local results and executes only policy-allowlisted read-only analyzers; task-aware context: `dairn context [query] [--change]` returns sourced, precision-labeled evidence with explicit UNKNOWNs. Both are advisory and never a Gate verdict.
